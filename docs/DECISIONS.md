# Журнал решений проекта «Дневник пловца»

## 2026-08-21 — Вытянутые карточки стилей

- **Проблема:** ребёнку должно быть легко выбрать стиль и попасть пальцем по элементу.
- **Решение:** широкие карточки высотой 112–136 px с радиусом 24 px; нажимается вся карточка.
- **Альтернативы:** квадратные плитки, текстовый список.
- **Причина:** крупная зона касания и место для названия вместе с изображением.
- **Последствия:** на телефоне карточки идут одной колонкой.

## 2026-08-21 — Тематические изображения

- **Проблема:** ребёнку полезно распознавать стиль по движению, а не только по тексту.
- **Решение:** изображения пловца с ясно видимой техникой; текстовое название обязательно.
- **Альтернативы:** интерфейс без иллюстраций, абстрактные иконки.
- **Причина:** изображение ускоряет распознавание и делает приложение привлекательнее.
- **Последствия:** пожелание «без иллюстраций» уточнено: декоративные изображения не нужны, функциональные навигационные изображения разрешены.

## 2026-08-21 — Морская палитра

- **Проблема:** нужен узнаваемый характер, связанный с плаванием.
- **Решение:** глубокий синий, бирюзовый и аквамариновый; небольшие коралловые и жёлтые акценты.
- **Альтернативы:** несвязанная многоцветная палитра, монохром.
- **Причина:** морская основа связывает продукт с бассейном, яркая экипировка добавляет контраст.
- **Последствия:** состояния никогда не кодируются только цветом.

## 2026-08-21 — Направление фотографий

- **Проблема:** стиль должен легко считываться на карточке.
- **Решение:** вид сверху/сверху под углом, бирюзовая вода, контрастная экипировка и видимый след движения.
- **Альтернативы:** портреты, трибуны, кадры без ясной фазы гребка.
- **Причина:** верхний ракурс показывает тело и руки и хорошо кадрируется в вытянутую форму.
- **Последствия:** для пяти стилей потребуются согласованные ассеты с focal point.

## 2026-08-21 — Референсы не являются ассетами

- **Проблема:** лицензия присланных изображений для продукта не подтверждена.
- **Решение:** не использовать их напрямую; создать или лицензировать финальные изображения.
- **Последствия:** перед выпуском нужно подготовить пять производственных ассетов.

## 2026-08-22 — Без отдельного экрана выбранной дисциплины

- **Проблема:** пустой экран дисциплины дублировал форму добавления результата и добавлял лишний шаг.
- **Решение:** карточка стиля на главной открывает выбор дистанции, после которого пользователь сразу переходит в форму с заполненными стилем и дистанцией. Раздел «Результаты» показывает единый список всех записей и фильтры.
- **Альтернативы:** оставлять пустую историю для выбранной дисциплины; повторно выбирать стиль и дистанцию на отдельном экране.
- **Причина:** быстрее сохранить результат, особенно ребёнку, и не показывать две конкурирующие кнопки добавления.
- **Последствия:** отдельный экран дисциплины удалён из основного пользовательского потока; история остаётся доступной через нижнюю навигацию.

## 2026-08-22 — Иерархия карточки результата

- **Проблема:** в общем списке стиль терялся среди служебной строки, а словесная подпись прогресса перегружала карточку.
- **Решение:** дата остаётся слева сверху, время — справа сверху; стиль показывается крупно с дистанцией рядом, тип и бассейн — под временем. Индикатор прогресса — крупная контурная стрелка рядом со временем без видимой словесной подписи.
- **Причина:** ребёнок и родитель быстрее считывают дисциплину, время и направление изменения.
- **Последствия:** для скринридера сохраняется текстовое описание стрелки; первая запись дисциплины по-прежнему не имеет индикатора.

## 2026-08-22 — Цветовой маркер стиля в списке результатов

- **Проблема:** в общем списке трудно быстро просканировать результаты разных стилей.
- **Решение:** тонкая левая полоса карточки обозначает стиль плавания; зелёный текст «Соревнование» остаётся меткой типа заплыва.
- **Причина:** используется уже существующая геометрия карточки без добавления новых декоративных элементов и без конкуренции со временем.
- **Последствия:** цвет дополняет, но не заменяет название стиля и текстовую метку соревнования.

## 2026-08-22 — Единая линия времени в карточках результатов

- **Проблема:** у первой записи дисциплины без стрелки время визуально сдвигалось вправо относительно остальных карточек.
- **Решение:** для времени выделена фиксированная колонка; его начало совпадает на всех карточках. Левая полоса, название стиля и время используют одну водную гамму каждого стиля.
- **Причина:** список легче сканировать, а ребёнок быстрее находит главное значение.
- **Последствия:** на очень узких экранах вторичная строка переносится ниже, не уменьшая размер времени.

## 2026-08-22 — Семейная синхронизация по общему коду

- **Проблема:** результаты с разных телефонов семьи не объединялись.
- **Решение:** локальная IndexedDB остаётся первичным хранилищем; при наличии сети приложение объединяет данные через семейный Cloudflare Worker. Доступ к семейному состоянию защищён общим семейным кодом, который вводится отдельно на каждом устройстве.
- **Причина:** сохраняется простой сценарий без регистрации и пароля, а запись результата остаётся доступной офлайн.
- **Последствия и риск:** общий код — не полноценная модель личных учётных записей. Его нельзя публиковать или передавать посторонним; для публичного многосемейного продукта потребуется более строгий доступ.
# 2026-08-22 — Пустой первый запуск профиля

- **Проблема:** демонстрационные имя и дата рождения могли быть приняты за реальные данные спортсмена.
- **Решение:** при первом запуске поля имени и даты рождения пустые и обязательны для создания профиля.
- **Дополнение:** имя сохраняется с прописной первой буквы; профиль не создаётся, пока не заполнены оба поля.

## 2026-08-22 — Подключение к семье на первом экране

- **Проблема:** член семьи на новом устройстве не должен повторно создавать профиль спортсмена, чтобы увидеть уже существующие результаты.
- **Решение:** под формой первого запуска показывается ссылка «Уже есть профиль в семье? Ввести код». Она открывает модальное окно для общего семейного кода и после успешной проверки загружает существующий профиль.
- **Причина:** путь занимает один короткий шаг и не добавляет регистрацию или отдельный экран.
- **Последствия:** неверный код не сохраняется на устройстве; при отсутствии сети пользователь видит понятную ошибку и может повторить попытку позднее.

## 2026-08-23 — Семейный сервер не кэшируется PWA

- **Проблема:** на Safari service worker мог вернуть устаревший кэш вместо сетевого ответа семейного сервера.
- **Решение:** кэшируется только собственный статический интерфейс приложения; запросы к Cloudflare Worker всегда идут в сеть. Версия service worker увеличена для принудительного обновления установленного приложения.

## 2026-08-23 — Обновление семейных данных на открытом устройстве

- **Проблема:** результат, добавленный на одном телефоне, мог не появиться на другом до его перезапуска или ручного нажатия синхронизации.
- **Решение:** при возвращении в приложение и каждые 30 секунд на видимом экране запускается безопасная повторная синхронизация. Карточка результата допускает перенос длинной пары «стиль + дистанция», не перекрывая время.

## 2026-08-23 — Карточки с длинным названием дисциплины

- **Проблема:** «Баттерфляй» и «Комплекс» вместе с дистанцией не помещаются на одной линии с временем на мобильном экране.
- **Решение:** в этих карточках время занимает отдельную строку, выровненную справа. Дата и служебная информация остаются выше, а название стиля и дистанция не сокращаются.
